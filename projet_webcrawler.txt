PLAN DE DÉVELOPPEMENT - PROJET SAAS WEBCRAWLER NO-CODE
=========================================

Auteur : Thumser Luc
Date de début : 12/11/2025
Technos principales : Django, Scrapy, Celery, Redis, PostgreSQL, Docker
Objectif : Créer un MVP de SaaS de webcrawler simple et automatisé, avec interface web et résultats téléchargeables.

-----------------------------------------
PHASE 0 - ASPECTS LÉGAUX ET ÉTHIQUES
-----------------------------------------

Objectif :
Garantir la conformité légale du service dès la conception, 
tout en protégeant l’utilisateur et le développeur de toute responsabilité liée à l’utilisation du webcrawler.

Principes fondamentaux :

Responsabilité de l’utilisateur :
Chaque utilisateur est pleinement responsable des URLs qu’il soumet à la plateforme.
Le service ne doit en aucun cas être utilisé pour extraire des données privées, protégées, ou contraires aux CGU d’un site tiers.
Une clause spécifique dans les Conditions Générales d’Utilisation (CGU) précisera que toute utilisation abusive, 
illégale ou contraire à la législation en vigueur relève exclusivement de la responsabilité de l’utilisateur.

Conformité RGPD (Règlement Général sur la Protection des Données) :
Aucune donnée personnelle n’est collectée ou traitée sans consentement explicite.
Les comptes utilisateurs sont limités à un strict minimum de données (email, mot de passe).
Les fichiers résultant des crawls ne sont pas analysés, 
exploités ni conservés par la plateforme au-delà de la durée strictement nécessaire au téléchargement par l’utilisateur.
L’utilisateur reste seul propriétaire de ses données et de ses résultats.

Prévention des abus et sécurité :
Mise en place de limites techniques (taux de requêtes, domaine crawlable, fréquence) 
pour éviter toute surcharge ou attaque involontaire sur des sites externes.
Politique “robots.txt respectée par défaut” pour éviter tout comportement non éthique.
Les crawlers sont exécutés dans un environnement isolé (conteneurs Docker) 
afin de garantir la sécurité du serveur et des utilisateurs.

Mentions légales et transparence :
Une page “Mentions légales” et “Politique de confidentialité” sera disponible sur le site, 
détaillant les responsabilités, 
les finalités de traitement et les droits des utilisateurs (accès, suppression, portabilité).
Aucune revente, partage ou exploitation des données utilisateurs ne sera effectuée, 
ni à des tiers ni à des fins commerciales externes.

Livrables :
CGU / Politique de confidentialité / Mentions légales (v1)
Processus de consentement RGPD
Page d’information “Utilisation responsable du webcrawler”
Mise en place de limites anti-abus (niveau serveur ou applicatif)

-----------------------------------------
PHASE 2 - BASE DJANGO
-----------------------------------------
Objectif :
- Poser les fondations du backend SaaS (auth, modèles, vues, API).

Tâches :
1. Créer le projet Django :
   django-admin startproject webcrawler_saas
2. Créer l'app principale :
   python manage.py startapp crawler
3. Configurer la base de données (SQLite pour début, PostgreSQL ensuite).
4. Créer les modèles :
   - User (auth Django)
   - CrawlTask (user, url, status, result_file, created_at)
5. Créer les vues/API :
   - POST /task/ (créer une tâche)
   - GET /task/{id}/ (statut + lien de téléchargement)
6. Créer un template HTML minimal ou API JSON (via Django Rest Framework).

Livrables :
- Projet Django fonctionnel avec CRUD de tâches
- Admin Django opérationnel

-----------------------------------------
PHASE 3 - INTÉGRATION DE SCRAPY
-----------------------------------------
Objectif :
- Intégrer un moteur de crawling fonctionnel avec Django.

Tâches :
1. Créer un projet Scrapy séparé :
   scrapy startproject corecrawler
2. Créer un spider simple (BasicSpider) qui prend une URL en argument.
3. Tester manuellement le spider sur des sites de test.
4. Ajouter Celery + Redis pour exécuter Scrapy en tâche asynchrone.
5. Connecter Django → Celery → Scrapy :
   - Quand une tâche est créée, Celery lance le crawl
   - Scrapy stocke le résultat dans un fichier CSV
   - Django met à jour le statut à "done" et ajoute le lien du fichier

Livrables :
- Crawl fonctionnel via interface Django
- Résultat téléchargeable

-----------------------------------------
PHASE 4 - AMÉLIORATION UX / NO-CODE
-----------------------------------------
Objectif :
- Rendre le système utilisable sans compétence technique.

Tâches :
1. Créer une interface web simple :
   - Formulaire d’ajout d’URL
   - Liste des tâches + statut
   - Bouton “Télécharger résultat”
2. Ajouter la possibilité de définir des sélecteurs CSS (no-code light)
   - Exemple : utilisateur saisit “.product-title” et “.price”
   - Sauvegarde dans la base
3. Adapter le spider pour lire les sélecteurs dynamiques.
4. Ajouter feedback utilisateur (progress bar ou statut visible).

Livrables :
- Interface simple utilisable par un utilisateur lambda
- Extraction paramétrable (semi no-code)

Tâches :
1. Conteneuriser l’application avec Docker :

   - Redis (broker Celery)
   - PostgreSQL (base)

4. Stockage fichiers :

5. (Optionnel) Intégrer Stripe pour paiements automatiques.

Livrables :
- Application en ligne
- Tâches exécutées automatiquement
- Monitoring opérationnel

PHASE 7 - GESTION DES COÛTS ET RENTABILITÉ
-----------------------------------------
Objectif :
- Prévoir les coûts fixes et marges nettes pour le SaaS.

Éléments à prendre en compte :
1. VPS-2 pour ≤30 utilisateurs, VPS-6 pour >30 utilisateurs (Service VPS d'OVH)
2. Site web OVH : ≈10€/mois
3. Stockage et backup : ≈5€/mois
4. Charges sociales autoentrepreneur : 22% du CA*
5. types d'abonnement, gratuit -> 3crawl/mois (version d'essai),offre 40 euros par mois les 3 premiers mois puis, offre 50 euros par mois pour crawl illimité.
5. Limite autoentrepreneur : 77 700€/an → avec abonnement 50€/mois, max ≈129 utilisateurs

Estimation bénéfice net annuel selon utilisateurs et VPS :
- 10 utilisateurs : ~4 416 €/an (~368 €/mois)
- 30 utilisateurs : ~13 776 €/an (~1 148 €mois)
- 50 utilisateurs : ~22 620 €/an (~1 885 €/mois)
